# Backend Mahabharat

A collection of small backend projects for learning Node.js and Express, built day by day.

## Projects

### day1-express
A basic Express.js server setup.
- Entry point: `app.js`
- Dependencies: `express`, `nodemon`

### file_upload/server
A file upload server built with Express and Multer.
- Entry point: `index.js`
- Dependencies: `express`, `multer`
